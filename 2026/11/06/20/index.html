赛博大肥鱼
Published in：2026-11-06 |

从零开始，在 Windows 本地养一条属于自己的“赛博大肥鱼”（AstrBot 保姆级避坑指南）

前言：什么是“大肥鱼”？

如果你经常混迹于 AI 圈或 B 站，大概率听说过“大肥鱼”的传说。它原本是网友对人工智能模型 DeepSeek 的拟人化爱称（因为其 Logo 是一条蓝色的鲸鱼）。后来，技术大佬们将它与 QQ 机器人框架结合，赋予了它傲娇、爱吃、甚至偶尔摸鱼的“大肥鱼”人格。

今天，我们就来记录一下，如何完全在本地（Windows 环境）、零成本（仅白嫖免费 API 额度） 地部署一只属于自己的 QQ 大肥鱼。整个过程可以说是跌宕起伏，如果你也打算折腾，这篇避坑指南请务必收好。

一、 准备工作（零成本方案）

在动手之前，你需要准备以下“零件”：

  1. 一个 QQ 小号：非常重要！不要用大号，第三方协议登录存在极小的风控封号风险。
  2. DeepSeek API Key：前往 DeepSeek 开放平台注册，新用户会赠送 500 万 Token 的免费额度，足够个人聊天用很久。
  3. AstrBot 一键启动器：机器人的“大脑”框架（前往 GitHub 下载最新的 x64-setup.exe）。
  4. 大肥鱼配置包：社区提供的 dafeiyu-config-pack，包含人格设定和几百张表情包。

二、 第一阶段：部署“大脑”（AstrBot 踩坑记）

1. 安装框架

下载并运行 AstrBot Launcher 后，直接点击「创建实例」，端口保持默认的 6185。

⚠️ 踩坑点 1：依赖安装卡在 60%
第一次启动实例时，程序需要安装 Python 组件和大量依赖包。由于网络原因，进度条极容易卡死。
解决方案：如果卡住太久，直接点取消删除实例。去启动器的「高级」设置里开启「中国大陆一键加速」，或者给你的代理软件开启全局/TUN 模式，然后重新创建实例。成功后，记得去日志里复制初始密码，登录 http://localhost:6185 后台。

2. 接入对话模型

在后台左侧「模型提供商」中，新增一个提供商。

  • 类型：DeepSeek（或 OpenAI Compatible）
  • Base URL：https://api.deepseek.com/v1
  • API Key：填入你的 sk- 密钥
  • 添加 deepseek-flash 模型（便宜且快），并在「配置文件」中将其设置为默认对话模型。

三、 第二阶段：接入“嘴巴”（QQ 连接辛酸史）

在 AstrBot 后台的「插件市场」搜索 NapCat_Go 插件，准备接入 QQ。

⚠️ 踩坑点 2：插件市场一直转圈，下载卡死
因为要从 GitHub 拉取数据，网络一波动就卡死。
解决方案：直接去浏览器的 GitHub 页面，手动下载插件包的 Source code (zip)，回到 AstrBot 插件页面，点击右下角的 + 号手动上传 ZIP 包安装。

⚠️ 踩坑点 3：NapCat 自动启动反复报错 cannot access local variable 'pw'
好不容易装好插件，却怎么也无法拉起 NapCat 核心。清理残留、重启都无效。
终极解决方案：放弃插件自动拉取，直接手动部署！

  1. 去 NapCat 官方 GitHub 下载 **NapCat.Shell.Windows.Node.zip**（这个包自带了运行环境，最省事）。
  2. 解压到一个纯英文路径下（如 D:\NapCat）。
  3. 右键点击里面的 launcher.bat，选择 以管理员身份运行。
  4. 等待黑窗口弹出二维码，用 QQ 小号扫码登录。
  5. 在 NapCat 的 WebUI 界面中，新建一个 WebSockets 客户端，URL 填入 ws://127.0.0.1:6199/ws。
  6. 看到 AstrBot 后台出现 aiocqhttp(OneBot v11) 适配器已连接，大功告成！

四、 第三阶段：注入灵魂（人格与记忆）

1. 变身大肥鱼

确保 AstrBot 和 NapCat 都在运行，双击运行配置包里的 导入大肥鱼.bat。按提示输入后台账号密码、你的 QQ 大号。当问及“记忆”和“语音”时，先输入 0 跳过。脚本会自动下载表情包和人格设定。

2. 关于长期记忆的探讨

导入完成后，AstrBot 会自动装上 LivingMemory 长期记忆插件。但这里有一个大坑：它需要“嵌入模型（Embedding Model）”才能工作，而 DeepSeek 目前没有这个接口。

  • 白嫖方案：去注册一个硅基流动或 Gitee 模力方舟账号，获取免费的 BAAI/bge-m3 模型接口，填到 AstrBot 中。
  • 躺平方案：直接用自带的短期记忆，或者去插件市场装一个纯本地无需 API 的 Memorix 插件。如果你嫌麻烦，其实光靠大肥鱼自带的上下文记忆，日常聊天也完全够用了。

五、 终极拷问：如何让它 24 小时在线？

目前所有的程序都跑在你的个人电脑上。一旦你关闭那个黑色的终端窗口，大肥鱼就会失联。 如果你想让电脑关机它也在线，只有两个出路：

  1. 买云服务器（推荐）：租一台便宜的 Linux 云服务器，使用宝塔面板或一键脚本，把 AstrBot 和 NapCat 部署到云端。
  2. 用闲置设备挂机：找一台家里不用的旧笔记本或旧手机，24 小时插电运行。

但在那之前，先别急着折腾上云。直接把这几个窗口最小化，打开 QQ，找你的小号发一句 /reset，然后发个表情包逗逗她吧。 享受一下折腾几小时后得到的赛博宠物，这才是最大的乐趣！

结语

本地部署 AI QQ 机器人，与其说是一项技术，不如说是一场与网络环境、依赖包和报错代码的“搏斗”。但在 QQ 里收到那句带有大肥鱼语气回复的瞬间，一切努力都值了。

祝你的大肥鱼永远不掉线！
