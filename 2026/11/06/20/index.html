从零开始，在 Windows 本地养一条属于自己的“赛博大肥鱼”（AstrBot 保姆级避坑指南)
Published in：2026-11-06 |

从零开始：纯小白在 Windows 本地部署“赛博大肥鱼”避坑全指南

📖 前言

“大肥鱼”是网友对 DeepSeek 的拟人化昵称。把本地部署的 AstrBot 框架和 QQ 结合起来，你就能拥有一只随时陪你聊天的 AI 宠物。
本文记录了我在 Windows 电脑上，全程白嫖（零成本）部署大肥鱼的真实全过程。如果你也是第一次折腾，请务必按照本文的“避坑”路线走，能帮你省去至少 5 个小时的抓狂。

🛠️ 第一步：搞定“大脑”基础环境 (AstrBot)

1. 下载与安装 AstrBot

  • 前往 GitHub 的 AstrBotDevs/astrbot-launcher/releases 页面。
  • 下载哪个？ 如果你用的是普通的 Intel 或 AMD 电脑，请下载带有 x64-setup.exe 字样的文件（千万别下 ARM64 或 Linux 版本）。
  • 双击安装包，一路“下一步”安装完毕。打开 AstrBot Launcher。

2. 创建实例（⚠️ 小白极易卡壳点）

  • 点击右上角的蓝色按钮 「+ 创建实例」。
  • 名称：随便填，比如 BigFish。
  • 版本：下拉选择最新版。
  • 端口：填入 6185（记住这个数字）。
  • 点击 「确定」。此时会弹出一个部署进度条。

🚨 避坑点 1：依赖安装卡在 60% 怎么办？
第一次创建实例时，后台要下载几十个组件包，极大概率会卡在 60% 或 80% 不动。

  • 解决办法：耐心等 5 分钟。如果完全不动了，直接点右上角关闭弹窗，把列表里的实例删掉。去左侧菜单点 「高级」，开启 「中国大陆一键加速」（如果你开着全局代理，请关掉代理），然后重新创建实例。第二次有了缓存，通常几分钟就能跑完。

3. 登录后台

  • 当实例状态变成 「运行中」 后，AstrBot 会弹出一个网页窗口，或者你点击列表里的 「日志」 按钮。
  • 在日志里找到 Initial password: xxxxx 这一行，复制这串密码。
  • 打开浏览器，输入 http://localhost:6185。账号输入 astrbot，密码粘贴刚才复制的。登录后系统会强制让你改一个新密码，改完记好。

🧠 第二步：给大肥鱼注入“灵魂” (接入 DeepSeek)

  • 去 DeepSeek 官网注册账号，获取一个 sk- 开头的 API Key。
  • 回到 AstrBot 后台，左侧点击 「模型提供商」 -> 「+ 新增」，选择 DeepSeek。
  • 把 API Key 粘贴进去，Base URL 保持默认的 https://api.deepseek.com/v1。
  • 点击 「保存并获取模型」，页面下方会加载出可用模型。点击 deepseek-flash（或者 pro）右侧的 + 号添加。
  • 注意：右上角的「保存配置」如果是灰色的，说明已经自动保存成功了，不用管它。
  • 最后去左侧 「配置文件」 里，把默认对话模型选为你刚添加的 deepseek-flash。

🔗 第三步：接入 QQ（⚠️ 本次折腾最大的血泪史）

请直接放弃 AstrBot 自带的插件市场自动安装！ 因为网络原因，它大概率会一直转圈圈，或者即使装上了也会报 pw 变量错误无法启动。我们直接手动部署 NapCat。

1. 下载正确的 NapCat 包

  • 前往 NapCat 的 GitHub 官方发布页：NapNeko/NapCatQQ/releases。
  • 下载哪个？ 千万别下错！请下载 **NapCat.Shell.Windows.Node.zip**（大约 118MB）。这个包内置了运行环境，最适合小白。
  • 下载后，解压到一个纯英文、无空格的路径下，比如 D:\NapCat。

2. 启动并扫码登录

  • 进入解压后的文件夹，找到 **launcher.bat**（或者 launcher-win10.bat）。
  • 右键点击它 -> 选择「以管理员身份运行」。
  • 此时会弹出一个黑色的 PowerShell 窗口，里面会滚出很多代码。保持这个窗口开着，千万别关！
  • 稍等片刻，窗口里会出现一个二维码（有时是一个链接）。掏出你的手机，用 QQ 小号 扫码登录。

3. 让 QQ 连上 AstrBot（⚠️ 极易选错的地方）

  • 扫码登录成功后，浏览器打开 http://127.0.0.1:6099/webui（如果提示输入 Token，去黑窗口日志里找 token=xxx 的链接点进去）。
  • 在左侧菜单找到 「网络配置」。
  • 点击「新建」，必须选择「Websocket 客户端 (Client)」！（选 Server 是连不上的）。
  • 启用：打开（变成粉色）。
  • URL：填入 ws://127.0.0.1:6199/ws。
  • Token：清空，什么都别填。
  • 点击 「保存」。

此时，切回 AstrBot 后台，左侧点击「机器人」，状态显示为绿色的 运行中 · aiocqhttp，就说明 QQ 成功接入了！

🎭 第四步：导入“大肥鱼”人格包

  • 前往 GitHub 下载 zexuanw958-svg/dafeiyu-config-pack，解压。
  • 确保 AstrBot 后台网页还开着。双击文件夹里的 **导入大肥鱼.bat**。
  • 按提示填写：后台地址（默认回车）、账号密码、你的 QQ 大号。
  • 记忆选项：输入 0（先跳过，稍后配）。
  • 语音选项：输入 0（先跳过）。
  • 脚本会自动下载几百张表情包和人格设定。
  • 导入完成后，在 QQ 里给机器人发一句 **/reset**，然后再发一句“你是谁”，看看她是不是变成傲娇大肥鱼了！

🧠 第五步：关于长期记忆的真相

导入脚本会自动帮你装上 LivingMemory 记忆插件。但这里有一个坑：它需要一个叫“Embedding（嵌入模型）”的东西才能把对话存入数据库，而 DeepSeek 官方没有这个接口。

  • 不想折腾方案：直接放着不管。AstrBot 自带的短期记忆能记住最近的几十条聊天，日常闲聊足够了。
  • 零成本白嫖方案：如果你非要让她记住你几天前说的话，去注册一个免费的硅基流动（SiliconFlow）账号，申请 API Key。在 AstrBot 的「模型提供商」里新增一个 OpenAI Embedding，模型填 BAAI/bge-m3，填上 Key 保存即可。

💻 六、 日常维护须知（划重点！）

  1. 绝对不能关的东西：那个运行着代码的黑色 PowerShell 窗口（NapCat）和 AstrBot 启动器，只要关掉，大肥鱼就会掉线。请把它们最小化。
  2. 怎么让它 24 小时在线：因为是在你本地的电脑跑，你一旦关机/睡眠，它就会失联。如果你想摆脱电脑的束缚，下一步就需要去租一台云服务器（Linux 环境），把它部署到云端。
  3. 被风控了怎么办：QQ 小号如果掉线或者提示异常，不用慌，重新打开 NapCat 黑窗口重新扫码即可。

折腾完毕，去 QQ 里享受你的赛博大肥鱼吧！
